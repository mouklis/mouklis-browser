# Mouklis Browser 1.0 — Binary Relink Kit

This directory documents the binary relinking materials for Mouklis Browser 1.0 and Cefrium SDK 0.19.0 (LGPL-3.0-or-later).

The separate relink-kit archive contains compiled Mouklis application classes and build resources, **not the original Mouklis Java/Kotlin source code**. Compiled classes may still be examined or reverse-engineered.

**Verification status:** An independent rebuild using the existing Cefrium 0.19.0 dependency succeeded in the developer's macOS environment. A rebuild using a modified Cefrium SDK, an end-to-end runtime test of that rebuilt APK, and a complete LGPL distribution/installation-information review have **not yet been verified**. The existence of this directory or archive is **not a certification of LGPL compliance**.

The Cefrium/Chromium and other third-party licence texts and source references remain in the repository root. Mouklis application code and trademarks remain distinct from those licences.

Do not use a test-built or unsigned APK as a production update.
